## 1. 🏢 Business Editions (SMB / Up to 300 Users)

> [!IMPORTANT]
> Business editions have a **hard ceiling of 300 user licenses per domain**. If an organization exceeds 300 users, it must upgrade to an Enterprise tier.

| Feature / Capability | Business Starter | Business Standard | Business Plus |
| :--- | :--- | :--- | :--- |
| **Max User Limit** | 300 users | 300 users | 300 users |
| **Storage per User** | **30 GB** Pooled Storage | **2 TB** Pooled Storage | **5 TB** Pooled Storage |
| **Shared Drives** | ❌ No (My Drive only) | ✅ Yes | ✅ Yes |
| **Google Meet Limit** | 100 participants | 150 participants | 500 participants |
| **Meet Recording & Noise Cancel** | ❌ No | ✅ Yes (Drive recording) | ✅ Yes + Attendance Tracking |
| **Google Vault (E-Discovery)** | ❌ Add-on required | ❌ Add-on required | ✅ **Included** |
| **Endpoint Management** | Basic Mobile Management | Basic Mobile Management | **Advanced MDM** (Wipe, Profiles, iOS) |
| **Security Controls** | Basic 2-Step Verification | Basic 2-Step Verification | Drive/Gmail DLP, Desktop Security |

## 9. 📊 Google Drive File, Folder & Storage Limitations

### ⬆️ Upload & Copy Limits
* **Daily User Upload/Copy Limit:** **750 GB per user within a rolling 24-hour window**.
* **Maximum File Upload Size:** **5 TB** per individual file.
  * *Overflow Rule:* If a single file upload exceeds 750 GB (e.g., a 2 TB file uploaded as the first item of the day), the upload **completes**, but further uploads/copies are blocked for 24 hours.
* **Large File Copy Limit:** Files larger than **750 GB cannot be copied directly inside Drive**; they must be downloaded locally and re-uploaded.

### 🆔 Account Item Creation Limit
* **500 Million Items:** Each account can create up to 500 million items total (includes files, folders, shortcuts, and items in Trash).
* *What Counts:* Files/folders created or uploaded by the user (even if ownership was later transferred), shortcuts, and Trash items.
* *What Doesn't Count:* Shared items owned/created by others, and permanently deleted items.

### 📁 Folder Item Limits & Nesting Depth
* **Direct Folder Item Limit:** Up to **500,000 items directly inside a single folder** (My Drive folders). Subfolder contents do not count toward the parent folder's 500k limit.
* **Shared Drive Total Limit:** Up to **500,000 total items** (files, folders, shortcuts combined) per Shared Drive.
* **Folder Nesting Depth:** Up to **100 folder levels deep**. In the 100th nested folder, users can store files and shortcuts, but cannot create further subfolders.

## 10. ⏱️ Gmail & Drive Restoration Time Periods & Retention

| Restoration Stage | Retention Window | Authorized Role | Technical Details |
| :--- | :--- | :--- | :--- |
| **End-User Trash** | **30 Days** | End User | Gmail Trash/Spam & Drive Trash items automatically purge permanently after 30 days. |
| **Admin Console Data Restore** | **Up to 25 Days** *after Trash purge* | Super Admin / Delegated Admin | Admins can restore permanently emptied Gmail/Drive data via `Admin Console > Users > Restore Data`. |
| **Deleted User Account Recovery** | **20 Days** *after account deletion* | Super Admin | Restores deleted user account, mailbox, and Drive contents intact. |
| **Google Vault Preservation** | **Indefinite** *(Per Retention Rules)* | Vault Admin | Preserves data backend even if purged by user/admin if an active Vault retention rule or legal hold exists. |

## 11. 🛠️ L3 Admin Troubleshooting & Service Account Quota Scenarios

| Issue / Error | Root Cause | Admin Solution |
| :--- | :--- | :--- |
| **Service Account API script fails with `403 Storage Quota Exceeded`** | Standalone service accounts (`client_email`) lack personal My Drive storage. | Use **Shared Drives** with `supportsAllDrives=true` or use **Domain-Wide Delegation (DWD)** to impersonate a licensed user. |
| **User cannot create new files despite unused storage** | User hit the 500 million item creation ceiling. | Empty Trash, permanently purge unused items, or shift item creation tasks to another account. |
| **Drive upload halts mid-day after uploading a 1 TB file** | Daily 750 GB upload quota triggered. | The 1 TB file completed uploading as an exception, but further uploads are paused for 24 hours. |
| **Unable to copy an 800 GB video file inside Shared Drive** | Direct server-side Drive copy limit is 750 GB per file. | Download the file locally and upload it to the target destination. |
| **Cannot create subfolders inside deep directory structure** | Nesting depth limit of 100 folders reached. | Restructure the directory hierarchy or move subfolders up to a shallower level. |
